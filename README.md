# 课程笔记知识库 · 在线协作版

## 快速启动

### Windows
双击 `start.bat` 即可。

### Mac / Linux
```bash
cd course-notes-kb
npm install   # 首次运行需要安装依赖
node server.js
```

启动后浏览器会自动打开 `http://localhost:8686`。

局域网内其他人通过 `http://你的IP:8686` 访问（启动时会打印 IP）。

## 角色说明

| 角色 | 权限 |
|------|------|
| **管理员** | 上传/编辑笔记、添加批注、管理课程目录、修改设置 |
| **访客** | 浏览所有笔记和批注、在批注下回复/解答 |

## 初始密码

- 管理员初始密码：`admin`（首次登录后请在设置中修改）
- 访客默认无口令，可直接登录（管理员可在设置中设访客口令）

## 数据存储

数据保存在服务器端 `data/data.json`，所有通过网址访问的人共享同一份数据。
管理员在设置中可以修改管理员密码和访客口令。

## 技术栈

- 后端：Node.js + Express
- 前端：纯 HTML/CSS/JS（单页应用）
- 数据：JSON 文件存储
- 上传：支持 .html / .md 文件
